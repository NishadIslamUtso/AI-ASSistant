## Session 2 — 2026-10-10 22:55 Asia/Dhaka — Pixel-parity pass on apps/01_claude-exact-pixel-clone

### Goal
Make apps/01 a *measured* exact clone of the 6 spec screenshots (191547, 191558, 191608, 191636, 191646, 191707) instead of an eyeballed one.

### Built (new tooling, sandbox-only)
- `apps/01_claude-exact-pixel-clone/scripts/shot.mjs` — Playwright driver: `node scripts/shot.mjs <name> <actions>`, actions `settings|apps|user|file|ctx|vault|today|chat|artifact`; clears localStorage so the sidebar always matches the spec seed.
- `/home/user/tools/compare.py` — grid pixel diff (`python3 tools/compare.py ref.png rendered.png 16 12`) + `compare.heatmap()`.
- `/home/user/tools/region.py`, `cropdiff.py` (ink-box diff of a crop), `geom.py` (standard geometry probe: sidebar edge, search/new-chat/composer/greeting boxes).

### Method
Screenshots are 1280x680 CSS at deviceScaleFactor 1.5 => 1920x1020 PNGs, the exact pixel size of the spec files, so **device px = CSS px x 1.5**. Every number in the source comments is a device-px measurement divided by 1.5.

### Fixes (all measured)
Sidebar: nav `mt-[67px]`, row 24 CSS, label `ml-[7px]`; chat row 25.3 CSS, group header 23.3 CSS, group `mb-[17px]`, list `mt-[17px]`; nav made `sticky top-0` **inside** the scroll container so the scrollbar track spans device y 148–960 like the spec; scrollbar 7 px, thumb `#3a3a39` / `#5a5957` hover (no `scrollbar-gutter`, so Windows keeps the correct 248 px content width).
Center: greeting centred as a block, `mb-[20px]`, block `pb-[35px]`; pill `marginTop 56`, bg `#111111`; transcript width Medium 586 (Narrow 480 / Wide 800); composer padding `15px 14px 7px`, textarea `display:block`, bottom row `mt-[18px]`, +/mic 18.
UserMenu: left 7 / bottom 35 / width 249, bg `#20201f`, border `#373736`, no divider under the e-mail row, API keys and Log out each own group.
ContextMenu: bg `#20201f`, border `#373736`, clamps inside the chat list (flips up).
Apps modal: body `#151515`, header `#1a1a19` (45), divider `#484847`, content `max-width: 853` centred, heading `mt-[30px]`, featured card `mt-[47px]`.
TitleBar: caption buttons 42 CSS.
